### **About:**
Create: Metalwork makes various molten metal mods work together by filling gaps so molten metals can be processed by any supported machines. Every stage you add increases yield per raw ore. [Create](https://www.curseforge.com/minecraft/mc-mods/create) is not required, but is essential. Read more [here](https://github.com/AverageAnime/create-metalwork-multiloader/wiki/Processing-Guide).

These mods are non-essential, but recommended.
* [AllTheOres](https://www.curseforge.com/minecraft/mc-mods/allthemodium-ores)
* [Create Metallurgy](https://www.curseforge.com/minecraft/mc-mods/create-metallurgy)
* [Create: Big Cannons](https://www.curseforge.com/minecraft/mc-mods/create-big-cannons)
* [The Factory Must Grow](https://www.curseforge.com/minecraft/mc-mods/the-factory-must-grow)

### **Current Content:**

* Dozens of molten metal fluids, crushed ores, and dusts. View list [here](https://github.com/AverageAnime/create-metalwork-multiloader/wiki/Content-List).
* Fluids and items are config based with clauses to avoid overlap. Read more [here](https://github.com/AverageAnime/create-metalwork-multiloader/wiki/Config-Options).

Read the full changelog [here](https://github.com/AverageAnime/create-metalwork-multiloader/blob/1.21.1/CHANGELOG.md).

Information regarding compatibility with other mods can be found [here](https://github.com/AverageAnime/create-metalwork-multiloader/wiki/Compatibility).
